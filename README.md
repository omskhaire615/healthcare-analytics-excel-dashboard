# Healthcare Analytics Dashboard | Excel

An Excel dashboard project exploring stroke-related patient data through summary metrics, charts, and interactive slicers.

## Project overview

This project uses Microsoft Excel to summarize a healthcare dataset and compare stroke status with selected demographic and health-related factors.

## Dashboard highlights

- **5,110 patient records** in the source worksheet
- **249 stroke cases** shown in the dashboard summary
- Average age and average BMI summary metrics
- Gender distribution
- Stroke counts by work type, smoking status, and residence type
- Comparisons involving hypertension, heart disease, BMI, and stroke
- Interactive slicers for gender, work type, smoking status, stroke, hypertension, and heart disease

## Tools

- Microsoft Excel
- PivotTables / PivotCharts
- Slicers and dashboard formatting

## Files

- `project.xlsx` — Excel workbook containing source data and dashboard worksheets

## How to explore

1. Download `project.xlsx`.
2. Open it in Microsoft Excel.
3. Open the **Healthcare Dashboard** worksheet.
4. Use the slicers to filter the charts and explore the dataset.

## Important note

This is an educational data-analysis project. The charts describe patterns in the supplied dataset; they do not establish causation and must not be used for medical diagnosis or clinical decision-making. Verify data cleaning and missing-value handling before drawing conclusions.
